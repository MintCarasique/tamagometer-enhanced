# Build artifacts

- `TamagometerDesktop.exe` — Windows desktop application.
- `TamagometerEnhanced.fap` — enhanced Flipper Zero companion; copy it to
  `SD Card/apps/Tools` and keep it open while using the desktop application.

The current FAP build targets official Flipper firmware 1.4.3 / API 87.1.
Rebuild the `flipper` submodule with `ufbt` when the firmware API changes.
